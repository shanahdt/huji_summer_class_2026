Group Task 11 — Field Tools

Asymmetrical Dynamics: Sampling Tools

Three separate tools for the matched-pairs sampling task: a random score picker, a random page-number roller, and a printable to-scale ruler.

01

Random score generator

Draws from a fixed pool of freely available IMSLP scores instead of IMSLP's site-wide random page button, which mostly lands on non-score pages. Click to draw your volume.

02

Random page-number generator

Check the total page count of the Complete Score PDF you drew above, enter it below, and roll. Navigate to that page number in the PDF to start your search for a hairpin.

—
03

Printable ruler

A separate, to-scale centimeter ruler for measuring hairpin length directly off a printed page. Printing this card only (not the whole page) keeps it accurate.

In the print dialog, set Scale = 100% / Actual size — turn off "Fit to page," or the physical measurement will be wrong.
